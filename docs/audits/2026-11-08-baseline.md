## 6. Comandos de reproducción

Ejecutar desde `despliegues-bada-react/`:

```powershell
# Estilos inline
(Get-ChildItem -Recurse src -Include *.jsx | Select-String -Pattern 'style=\{\{' -AllMatches | Measure-Object).Count
(Get-ChildItem -Recurse src -Include *.jsx | Select-String -Pattern 'style=\{\{' | Select-Object -ExpandProperty Path -Unique | Measure-Object).Count

# Hex
(Get-ChildItem -Recurse src -Include *.css | Select-String -Pattern '#[0-9a-fA-F]{3,8}\b' -AllMatches | ForEach-Object { $_.Matches } | Measure-Object).Count
(Get-ChildItem -Recurse src -Include *.css | Select-String -Pattern '#[0-9a-fA-F]{3,8}\b' -AllMatches | ForEach-Object { $_.Matches } | ForEach-Object { $_.Value.ToLower() } | Sort-Object -Unique | Measure-Object).Count

# Archivos CSS
(Get-ChildItem -Recurse src -Include *.css | Measure-Object).Count

# ARIA
(Get-ChildItem -Recurse src -Include *.jsx | Select-String -Pattern 'aria-label' | Measure-Object).Count
(Get-ChildItem -Recurse src -Include *.jsx | Select-String -Pattern 'role=' | Measure-Object).Count
(Get-ChildItem -Recurse src -Include *.jsx | Select-String -Pattern 'aria-live' | Measure-Object).Count

# Media queries
(Get-ChildItem -Recurse src -Include *.css | Select-String -Pattern '@media' | Measure-Object).Count

# Variables usadas sin definir
$css = Get-ChildItem -Recurse src -Include *.css
$defined = @{}; foreach($f in $css){ Select-String -Path $f.FullName -Pattern '(--[a-zA-Z0-9-]+)\s*:' -AllMatches | ForEach-Object { $_.Matches | ForEach-Object { $defined[$_.Groups[1].Value] = $true } } }
$used = @{}; foreach($f in $css){ Select-String -Path $f.FullName -Pattern 'var\((--[a-zA-Z0-9-]+)' -AllMatches | ForEach-Object { $_.Matches | ForEach-Object { $used[$_.Groups[1].Value] = $true } } }
$used.Keys | Where-Object { -not $defined.ContainsKey($_) } | Sort-Object
```

## 7. Observaciones sobre el baseline

- La cifra de variables indefinidas es **4 reales + 1 con fallback**, no 1 como se estimó inicialmente. Todas se concentran en `modal-history.css`, que además no está en el punto de entrada.
- Las hojas huérfanas son **6 desde `main.css`** más `modal-history.css` importada desde un componente. La spec debe reflejar esta cifra al ejecutar `P1-07`.
- `detail-header.css` no está importado: el componente `DetailHeader.jsx` depende de estilos que nunca se cargan por la vía oficial. Es un defecto funcional, no solo de orden.
- Los 30 tamaños de fuente y 14 radios confirman la ausencia de escala tipográfica.
